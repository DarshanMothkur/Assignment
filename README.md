# Simple Interest Calculator

## Project Name
Simple Interest Calculator

## Description
This project is a simple Bash-based calculator that computes simple interest based on the principal amount, rate of interest, and time period provided by the user.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Input
- Principal amount
- Rate of interest
- Time period

## Output
The calculated simple interest is displayed to the user.
